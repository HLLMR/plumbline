# Examples

`plumbline-self-hosting-pilot.md` is the one published example: an
evidence-backed report on this repository's own ten-work-order self-hosting
pilot, drawn only from the aggregate records in `governance/STATE.md`,
`governance/LOG.md`, and the ratified `governance/decisions/DR-002.md`. It
distinguishes measured results from controlled inference, states the
provider envelope and its session-local limits, and makes no comprehensive
enforcement or proof claim.

Add a further example only after a real pilot produces evidence worth
preserving; do not invent a nominal "governed project" merely to populate
this directory.
