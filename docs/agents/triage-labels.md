# Triage labels

Every triaged issue has exactly one category and one workflow state.

| Role | Public label | Meaning |
|---|---|---|
| Category | `bug` | Existing behavior is broken, misleading, or unsafe. |
| Category | `enhancement` | A new bounded capability or improvement. |
| State | `needs-triage` | Maintainer evaluation is in progress. |
| State | `needs-info` | The reporter must provide specific missing evidence. |
| State | `ready-for-agent` | Fully specified and safe for an agent to pick up. |
| State | `ready-for-human` | Requires human implementation or judgment. |
| State | `wontfix` | The project will not action the request. |

Additional descriptive labels such as `documentation` may coexist with those
two required roles.
