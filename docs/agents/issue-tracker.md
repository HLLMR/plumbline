# Issue tracker: GitHub

Public defects and enhancements live in
[`HLLMR/writwall`](https://github.com/HLLMR/writwall/issues). Use GitHub
issues and pull requests for public discussion. Never paste the private
governed-source history, private paths, secrets, disclosure patterns, or other
projects into an issue or PR.

## Conventions

- Create issues with the repository forms under `.github/ISSUE_TEMPLATE/`.
- Every AI-generated issue or triage comment begins with
  `> *This was generated by AI during triage.*`.
- A `ready-for-agent` issue has one durable agent-brief comment describing
  current behavior, desired behavior, acceptance criteria, and exclusions.
- A pull request links its issue with `Closes #<number>` and contains only the
  public projection of accepted source changes.
- Maintainers close issues through the merged pull request, not by claiming an
  unmerged private implementation fixed the public package.
