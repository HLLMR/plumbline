# Domain authority for contributor agents

Writwall is a single-context repository, but it uses its own document-control
model rather than a generic `CONTEXT.md` or ADR directory.

Before proposing or implementing a change, read only the authorities routed to
the affected surface:

- `DOCTRINE.md` and `decisions/` for methodology semantics and ratification;
- `README.md`, `START-HERE.md`, and `ADOPTING.md` for the public human ramp;
- `adapters/*/README.md` and `SECURITY.md` for enforcement claims;
- `CONTRIBUTING.md` for public issue, test, DCO, projection, and PR mechanics;
- the active project charter, work order, Plan sections, State, and Routing in
  the private governed source when the maintainer supplies them.

Do not infer current authority from closed history, a GitHub discussion, an
unmerged PR, or an agent's memory. Public issues record defects and proposals;
they do not ratify Doctrine or project intent.
